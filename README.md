# HYPERTROPHY brand

The identity for Hypertrophy, kept out of the product repository so the app
build stays free of marketing assets and store paperwork.

```
brand/       Palette, typography, voice, and logo rules
brand/wordmark.png
play-store/  Listing copy, Data safety answers, submission checklist
play-store/assets/  Icon and feature graphic
```

## Ground rules

- No emojis anywhere, including store copy. This is the same rule the codebase
  follows.
- The wordmark is drawn for dark surfaces. The word "Hyper" is white and
  disappears on light backgrounds, so use the icon or a dark tile instead.
- Every asset here is produced from the same tokens and fonts the app ships:
  Obsidian Forge, Space Grotesk, Plus Jakarta Sans, JetBrains Mono.
- Source of truth for colour and type is
  [`AGENTS.md`](https://github.com/Hypertrophy-app/hypertrophy-android/blob/main/AGENTS.md)
  and the version catalog. If they diverge, the app wins and this repo is
  corrected.
